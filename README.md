아기티큐 200일선 매매법 공식 위젯 (AGITQ 200-day MA Official Widget)
"사람이 마음으로 자기의 길을 계획할지라도 그의 걸음을 인도하시는 이는 여호와시니라" (잠언 16장 9절)

매일 아침 증권사 앱을 켜고 차트를 확인하는 번거로움 없이, 당신의 아이폰 홈 화면에서 200일선 매매법의 모든 것을 한눈에 파악하세요. 이 위젯은 단순히 주가를 보여주는 것을 넘어, 우리가 따라야 할 원칙과 행동을 매일 알려주는 당신만의 똑똑한 투자 나침반입니다.

주요 기능 (Key Features)
시장 상황 자동 판단: 현재 TQQQ의 위치에 따라 [하락], [집중 투자], [과열] 상황을 색상과 텍스트로 명확하게 알려줍니다.

핵심 지표 시각화: 복잡한 차트를 걷어내고, 우리에게 꼭 필요한 **3개의 선(TQQQ 현재가, 200일선, +5% 엔벨로프선)**만을 미니 차트로 그려줍니다.

정확한 데이터 표시: TQQQ 현재가, 200일선 가격, +5% 엔벨로프선 가격을 정확한 수치로 제공합니다.

빠르고 안정적인 작동: 하루에 한 번만 데이터를 가져와 저장해두는 '캐싱(Caching)' 기술로 매우 빠르고 안정적으로 작동합니다.

블로그 바로가기: 위젯을 터치하면 언제든 공식 블로그로 이동할 수 있습니다.

설치 방법 (Installation Guide)
App Store에서 Scriptable 앱을 먼저 설치하세요.

이 Gist 페이지 우측 상단의 Raw 버튼을 누르세요.

전체 코드가 나타나면 모두 선택하여 복사하세요 (Ctrl+A, Ctrl+C).

Scriptable 앱을 열고 우측 상단의 + 버튼을 눌러 새 스크립트를 만드세요.

복사한 코드를 붙여넣고, 스크립트 이름을 아기티큐 200일선 위젯 등으로 저장하세요.

아이폰 홈 화면을 길게 눌러 위젯 추가 모드로 들어간 후, Scriptable 위젯을 선택하세요.

추가된 위젯을 다시 길게 눌러 위젯 편집으로 들어간 후, Script 항목에서 방금 저장한 스크립트를 선택하면 완료됩니다.

English Description
This Scriptable widget visualizes the 'AGITQ 200-day Moving Average' trading strategy for the TQQQ ETF on your iPhone's home screen. It automatically analyzes the market situation based on the strategy's rules and displays key indicators.

Features:

Real-time market situation analysis (Decline, Focus, Overheat).

Chart visualization of the current price, 200-day MA, and +5% Envelope line.

Key price data display.

Built-in caching for speed and stability.
